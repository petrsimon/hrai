# HRAI brand assets

Transparent raster assets for the HRAI website and editor shell.

## Recommended usage

- `hrai-logo-horizontal-400.png` — standard-density navigation header
- `hrai-logo-horizontal-800.png` — high-density navigation header
- `hrai-wordmark-400.png` — standalone flame wordmark
- `hrai-dragon-mark-256.png` — standalone product mark
- `favicon.ico` and `favicon-*.png` — browser favicons
- `apple-touch-icon.png` — 180×180 Apple touch icon
- `web-app-icon-192.png` and `web-app-icon-512.png` — manifest icons

The selected horizontal logo combines the four-legged sapphire-blue dragon with the readability-focused flame wordmark (concept B). All PNG files preserve alpha transparency.

## Palette

- Deep blue: `#086788`
- Sky blue: `#3AA7E8`
- Flame yellow: `#FFBF1F`
- Flame orange: `#FF7A21`
- Coral: `#F45B4F`

These generated raster assets should be manually redrawn as reviewed vector paths before large-format print production or trademark registration.
